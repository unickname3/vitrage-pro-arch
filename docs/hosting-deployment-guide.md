# Инструкция по разворачиванию сайта на хостинге (Spaceweb и аналоги)

> **Для VPS от sweb.ru (SpaceWeb)** есть отдельная подробная инструкция:
> [`docs/vps-deployment-swebru.md`](vps-deployment-swebru.md).
> Здесь — общий порядок для обычного веб-хостинга.

Сайт — WordPress + готовая тема `vitrage-pro` (дизайн повторяет исходный сайт,
админка для владельца без плагинов). Всё, что нужно техническому специалисту —
установить WordPress, загрузить тему и запустить импорт контента (один клик).

## 1. Что нужно заранее
- Домен `vitrage-pro.ru` (и доступ к DNS).
- Хостинг с PHP 8.0+, MySQL/MariaDB, HTTPS (Let's Encrypt). Например, Spaceweb.
- Доступы: панель хостинга, база данных, почта для заявок с формы.

## 2. Подготовка хостинга
1. Создай сайт/виртуальный хост для `vitrage-pro.ru`.
2. Включи SSL-сертификат.
3. Создай базу данных и пользователя БД. Запиши параметры:
   `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`.

## 3. Установка WordPress
1. Скачай свежий WordPress с ru.wordpress.org и загрузи в корень сайта.
2. Запусти установку через браузер, укажи параметры БД, создай администратора.
3. `Настройки → Постоянные ссылки` → выбери «Имя записи» (тема сделает это сама
   при активации, но проверить не помешает).

## 4. Установка темы
Тема лежит в репозитории: `wordpress/wp-content/themes/vitrage-pro/`
или готовый архив: `downloads/vitrage-pro-theme.zip` (36 МБ, включает контент).

Способ A (рекомендуется на Spaceweb):
1. Распакуй `vitrage-pro-theme.zip` через файловый менеджер хостинга или FTP
   в `wp-content/themes/` (должна получиться папка `wp-content/themes/vitrage-pro/`).
2. В админке: «Внешний вид → Темы» → активируй тему «Vitrage Pro».

Способ B (если лимит загрузки позволяет, обычно до 64–128 МБ):
1. «Внешний вид → Темы → Добавить → Загрузить тему» → выбери
   `vitrage-pro-theme.zip` → «Установить» → «Активировать».

При активации тема автоматически:
- создаёт страницы: Мастерская, Новости, Цены, Контакты, Политика конфиденциальности;
- создаёт меню (с категориями галереи) и назначает его;
- создаёт 10 категорий галереи (Окна, Двери, Мозаика и т.д.);
- настраивает постоянные ссылки и главную страницу.

## 5. Импорт контента (один клик)
В админке: «Настройки сайта → Импорт контента» → «Запустить импорт».

Импорт создаст:
- 10 категорий галереи с описаниями;
- 202 работы с фотографиями (фото копируются в медиатеку);
- 5 сотрудников команды с фото и биографиями;
- 3 отзыва;
- 3 новости;
- заполнит настройки сайта (контакты, тексты главной, форму).

## 6. Проверка перед запуском
1. Открой сайт: главная, `/gallery/`, `/gallery/okna/`, `/komanda/`, `/reviews/`,
   `/news/`, `/price/`, `/contacts/`.
2. Проверь форму на `/contacts/`: отправь тестовое письмо.
3. Если письмо не дошло — заполни SMTP: «Настройки сайта → Форма и почта»
   (бесплатная Яндекс.Почта для домена или почта хостинга).
4. Проверь мобильную версию и скорость.

## 7. Редиректы со старых URL
Готовые правила:
- Apache: `ops/prod-vitrage-pro-ru.htaccess` (скопировать в корневой `.htaccess`);
- Nginx: `ops/prod-vitrage-pro-ru.nginx.conf`.

Проверка: `bash ops/check-redirects-curl.sh "https://vitrage-pro.ru"`.

## 8. Запуск (go-live)
1. Сделай backup файлов и БД.
2. Направь DNS домена на прод-хостинг.
3. Smoke-check: главная, галерея, категория, контакты + форма, 5–10 старых
   `.html` URL (должны отдать 301).

## 9. Поддержка после запуска
- Ежемесячно: обновление WordPress (тема обновляется по мере необходимости).
- Периодически: проверка форм и бэкапов.
- Контент владелец меняет сам через админку (см. `docs/client-handover-guide.md`).
