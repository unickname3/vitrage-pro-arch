# Маппинг контента (CMS)

Тема `vitrage-pro` управляет контентом без плагинов. Данные для разового
импорта лежат в `wordpress/wp-content/themes/vitrage-pro/content/data.json`
(генерируются скриптом `ops/generate_theme_content.py` из статики исходного сайта).

## Типы контента

### gallery_item — «Работа» (фото в галерее)
- Источник: `gallery/*.html` → каждое фото = одна запись.
- Поля:
  - `post_title` — название работы (подпись фото).
  - `thumbnail` — фотография (выбирается в мета-боксе «Фото работы»).
  - `gallery_category` — таксономия (альбом): Окна, Двери, Мозаика и т.д.
  - `menu_order` — порядок в категории.
- URL: архив `/gallery/` (сетка категорий), категория `/gallery/<slug>/`,
  отдельная работа `/work/<slug>/`.

### team_member — «Сотрудник»
- Источник: `komanda/spec-*.html`.
- Поля:
  - `post_title` — ФИО.
  - `vp_team_position` — должность (мета-поле).
  - `thumbnail` — фото.
  - `post_content` — биография.
- URL: `/komanda/`, `/komanda/<slug>/`.

### review_item — «Отзыв»
- Источник: `reviews/review-*.html`.
- Поля:
  - `post_title` — автор.
  - `vp_review_city` — город/компания (мета-поле).
  - `post_content` — текст отзыва.
- URL: `/reviews/`, `/reviews/<slug>/`.

### post — «Новости»
- Источник: `news/news-*.html`.
- Поля стандартные: заголовок, текст, миниатюра.
- URL: `/news/` (страница записей), `/news/<slug>/`.

### page — статические страницы
- Мастерская `/about/`, Цены `/price/`, Контакты `/contacts/`,
  Политика конфиденциальности `/privacy/`.
- Поля: стандартный редактор WordPress.

## Глобальные настройки (страница «Настройки сайта»)
- Контакты: телефон, дополнительный телефон, email, адрес, часы работы,
  VK, WhatsApp, Telegram.
- Главная: слайды hero (изображение + заголовок), текст «О мастерской»,
  заголовки секций, кнопки CTA.
- Футер: текст, копирайт, подписка.
- Форма: получатель, тема письма, сообщение об успехе, SMTP.

## Как импортировать
1. Установить WordPress и активировать тему.
2. «Настройки сайта → Импорт контента» → «Запустить импорт».

Импорт идемпотентен по слагам (повторно один и тот же контент не создаётся).
