# Инструкция для владельца сайта (админка)

Сайт работает на WordPress. Всё управление — в админке по адресу
`https://vitrage-pro.ru/wp-admin/` (логин и пароль вы получите при установке).

## Краткая шпаргалка

| Что нужно сделать | Куда зайти в админке |
|---|---|
| Изменить телефон/email/адрес | «Настройки сайта» → «Контакты» |
| Изменить тексты и слайды на главной | «Настройки сайта» → «Главная страница» |
| Добавить фотографию работы | «Галерея» → «Добавить фото» |
| Добавить сотрудника | «Команда» → «Добавить сотрудника» |
| Добавить отзыв | «Отзывы» → «Добавить отзыв» |
| Написать новость | «Записи» → «Добавить запись» |
| Изменить тексты страниц (Цены, Мастерская) | «Страницы» → нужная страница |
| Настроить почту для заявок | «Настройки сайта» → «Форма и почта» |

## 1. Контакты и тексты (главный раздел)

Меню «Настройки сайта» (в левом меню админки, в самом верху):

- **Контакты** — телефон, дополнительный телефон, email, адрес, часы работы,
  ссылка ВКонтакте, WhatsApp, Telegram.
- **Главная страница** — слайды в начале главной (фото + заголовок),
  текст секции «О мастерской», заголовки секций, кнопки.
- **Футер** — текст и копирайт внизу сайта.
- **Форма и почта** — куда приходят заявки с формы и настройки SMTP
  (нужно только если письма не доходят).

После изменений нажмите «Сохранить настройки» внизу страницы.

## 2. Галерея (фотографии работ)

Каждая фотография — это отдельная «Работа» в категории (альбоме).

1. «Галерея» → «Добавить фото».
2. Введите название (например, «Окно в прихожей»).
3. Нажмите «Выбрать фото» и загрузите фотографию из компьютера.
4. Справа в блоке «Категории галереи» отметьте категорию (Окна, Двери и т.д.).
5. При желании добавьте описание в текстовый редактор.
6. Нажмите «Опубликовать».

Фото появится на странице категории автоматически. Чтобы заменить фотографию —
откройте работу, нажмите «Заменить фото» и выберите новую.

Порядок фотографий: «Атрибуты страницы → Порядок» (меньше число — фото выше).

## 3. Команда

1. «Команда» → «Добавить сотрудника».
2. ФИО — заголовок записи.
3. Должность — в блоке «Должность».
4. Фото — «Миниатюра записи» (справа) → «Задать миниатюру».
5. Биография — в текстовом редакторе.
6. «Опубликовать».

## 4. Отзывы

1. «Отзывы» → «Добавить отзыв».
2. Имя автора — заголовок записи.
3. Город/компания — в блоке «Автор отзыва».
4. Текст отзыва — в редакторе.
5. «Опубликовать».

## 5. Новости

1. «Записи» → «Добавить запись».
2. Заголовок, текст, при желании — изображение («Задать миниатюру»).
3. «Опубликовать».

## 6. Цены и другие страницы

«Страницы» → откройте «Цены» (или «Мастерская»). Текст редактируется как в
обычном документе: абзацы, заголовки, списки, картинки. «Обновить».

## 7. Полезные советы

- Загружайте фотографии шириной 1600–2200 px, но не тяжелее 500 КБ
  (большие файлы замедляют сайт).
- Для каждого фото заполняйте название — оно становится подписью и alt-текстом.
- Перед публикацией проверяйте страницу на телефоне.

## 8. Безопасность и обслуживание

- Не сообщайте никому пароль от админки.
- Раз в месяц заходите в админку и обновляйте WordPress, если он предложит
  (кнопка «Обновить» сверху).
- Если что-то сломалось — обратитесь к техническому специалисту, который
  устанавливал сайт, и покажите это описание.
