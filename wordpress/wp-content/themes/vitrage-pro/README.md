# Vitrage Pro — тема WordPress

Тема для сайта-визитки студии художественных витражей «Витраж Про».
Воспроизводит дизайн исходного сайта vitrage-pro.ru и даёт владельцу
удобную админку **без плагинов**.

## Состав темы

```
vitrage-pro/
├── assets/                  # дизайн-ассеты исходного сайта
│   ├── vendor/              # bootstrap, animsition, lightgallery, owl, isotope и др.
│   ├── css/                 # theme.css, helper.css, dark-style.css, custom.css, admin.css
│   ├── js/                  # theme.js, custom.js, admin.js
│   └── img/                 # фоновые изображения и паттерны
├── content/                 # данные для разового импорта (data.json + images/)
├── inc/
│   ├── cpt.php              # типы записей: Галерея, Команда, Отзывы
│   ├── meta-boxes.php       # удобные поля в админке (без ACF)
│   ├── settings-page.php    # «Настройки сайта»: контакты, тексты, слайды
│   ├── form.php             # форма обратной связи + SMTP
│   ├── setup.php            # автогенерация страниц, меню, категорий
│   └── importer.php         # разовый импорт контента из content/
├── front-page.php           # главная (hero, о мастерской, галерея, отзывы, CTA)
├── header.php / footer.php
├── archive-*.php / single-*.php / taxonomy-gallery_category.php
├── home.php                 # новости
├── page.php / page-contacts.php
└── style.css
```

## Установка

1. Скопировать папку `vitrage-pro` в `wp-content/themes/` (или загрузить zip
   через «Внешний вид → Темы → Добавить → Загрузить тему»).
2. Активировать тему. При активации автоматически создаются:
   - страницы: Мастерская, Новости, Цены, Контакты, Политика конфиденциальности;
   - меню с категориями галереи;
   - категории галереи (10 шт., как на исходном сайте);
   - настраиваются постоянные ссылки (`/%postname%/`).
3. Заполнить сайт контентом:
   - «Настройки сайта → Импорт контента» — один клик, создаст работы,
     команду, отзывы, новости и перенесёт все фотографии (202 шт.) из
     папки `content/` в медиатеку WordPress.
4. Проверить «Настройки сайта» (контакты, тексты, слайды, форму).

## Что умеет владелец (без программиста)

- **Настройки сайта** — телефоны, email, адрес, соцсети, тексты главной,
  слайды, футер, настройки почты и формы.
- **Галерея** — добавить работу: название + фото + категория.
  Категории — это альбомы (Окна, Двери, Мозаика и т.д.).
- **Команда** — сотрудники: ФИО, должность, фото, биография.
- **Отзывы** — автор, город, текст.
- **Новости** — обычные записи WordPress.
- **Цены / Мастерская / Политика** — обычные страницы с редактором.

## Форма обратной связи

Шорткод `[vp_contact_form]` уже вставлен в страницу «Контакты».
Письма приходят на адрес из «Настройки сайта → Форма и почта».
Если письма не доходят — там же заполняется блок SMTP (бесплатная
Яндекс.Почта для домена или почта хостинга).

## Примечания

- Font Awesome и Google Fonts подключаются с CDN (как на исходном сайте).
  При желании их можно захостить локально.
- Контент в `content/` сгенерирован скриптом `ops/generate_theme_content.py`
  из статической копии исходного сайта.
